# Modul M151 — Datenbanken in Web-Applikationen einbinden

Coursework and exercises for the Swiss IT module **M151** ("Integrating databases into
web applications"). Each exercise lives in its own subfolder under `Uebungen/` with the
task description and any accompanying code.

## Contents

- `Uebungen/Uebung0/` — setup / working preparation (`Uebung0.md`).
- `Uebungen/Uebung1-1/` — a minimal Node.js HTTP server (`server.mjs`) plus its task
  description.

More exercises are added here as the module progresses; the repository serves as a
personal reference for the techniques covered.

## Tech

- Node.js (native `http` module)
- SQL / databases (module topic)

## Run an exercise

For the Node exercises, run the server file directly, e.g.:

```bash
node Uebungen/Uebung1-1/server.mjs
```

Then open http://localhost:8080.
